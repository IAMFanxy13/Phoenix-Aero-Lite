# Security policy

The project is pre-release. Report vulnerabilities privately through GitHub private vulnerability reporting after the repository is published. Do not open a public issue containing exploit details, proprietary CAD, credentials or local paths.

Supported security fixes target the latest development branch only. Include affected version/commit, impact, reproducible steps with non-sensitive fixtures and a suggested mitigation if available.

The server is designed for single-user loopback operation. Do not expose it to a LAN or the internet. See `docs/security/THREAT_MODEL.md`.

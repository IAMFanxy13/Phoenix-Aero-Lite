# Support

Use GitHub Issues for reproducible bugs, feature requests and scientific-result questions after publication. Include the Phoenix commit, Windows/Python/SU2/Gmsh versions, non-sensitive input description, error code and relevant sanitized logs.

Do not upload private CAD. For solver-result questions, state convergence status, mesh evidence, Y+, validation level and whether the comparison conditions truly match.

Commercial support, certification and flight-safety advice are not provided.

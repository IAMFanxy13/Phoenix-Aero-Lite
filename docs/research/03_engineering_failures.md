# 工程失败模式与防护

| 失败模式 | 证据类别 | 防护/可观测性 |
|---|---|---|
| 启动工作目录落在只读 WindowsApps | 本项目已复现并修复 | 项目根从 EXE 反向发现；所有 case 路径固定在项目或显式用户目录 |
| Gmsh STEP 导入后并非单一闭合实体 | 官方能力边界 + 本地经验 | OCC healing 后重新检查实体/面/包围盒；失败即停止，不强行网格 |
| OCC 布尔差或边界层失败 | Gmsh 社区常见工程风险 | 保留阶段日志；物理组、非流形、负质量和近壁层证据作为硬门槛 |
| 网格“生成成功”但不适合阻力预测 | CFD 工程经验 | 区分 preview/fast/fine；没有近壁层证据时禁止给出高可信 CD |
| SU2 返回码 0 但残差停滞 | 本项目 `example_model.STEP` 真实证据 | 工作流完成与可信度分开；`stagnated/max_iterations` 不得标记为成功 |
| 只看残差、不看力系数平台 | [SimScale Result Control](https://www.simscale.com/docs/simulation-setup/result-control/) 与 SU2 history | 联合残差下降、CL/CD 最近窗口跨度、非有限值和退出原因 |
| 临近失速的稳态 RANS 周期振荡 | 论文/工程经验 | 标为谨慎或无效；首版不自动把稳态振荡解释为收敛，建议 URANS/降低迎角 |
| Web 请求线程直接运行 CFD | FastAPI 官方后台任务 caveat | API 仅提交；单机任务服务在线程中调用既有管线，最多一个重任务；可取消 |
| 上传路径穿越/覆盖源模型 | Web 安全基本要求 | 只接受 `.step/.stp`，清理文件名，写入任务专属目录，限制大小，不信任客户端路径 |
| 浏览器退出导致任务状态丢失 | 工程经验 | 状态与事件落盘到任务目录；API 重启后可读取历史摘要 |
| 将静态图片/假数据当仿真结果 | 项目原则 | 只有真实产物存在且 provenance 完整时提供下载；测试夹具显式标识 |

## 保守重算边界

自动重算必须可审计且最多一次。首个 Web MVP 先实现“给出重试建议和显式重试入口”，不在没有真实参数验证前自动修改 CFL/松弛参数；避免用未经验证的自动调参制造虚假成功。后续在 NACA0012 与真实 STEP 基线上确定保守配置后再启用自动重算。

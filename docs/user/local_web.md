# Phoenix Aero Lite 本地网页

## 🚀 启动

双击项目根目录的 `Start_Phoenix_Aero_Lite.cmd`。

- 默认自动打开：`http://127.0.0.1:8000/`
- 不打开浏览器：添加参数 `-NoBrowser`
- 只检查环境：添加参数 `-CheckOnly`
- 更换端口：添加参数 `-Port 8001`
- 仅监听本机回环地址，不开放到局域网。

## 🛩️ 使用

1. 上传一个 `.STEP` 或 `.STP` 封闭实体。
2. 在三维模型中确认方向并点选左右主翼。
3. 输入速度、迎角和质量。
4. 点击开始分析；完成后查看可信度、压力、Y+、速度截面和流线。

自动参考量会显示来源、依据和置信度，允许人工覆盖，并保留覆盖记录。

## ⚠️ 科学门槛

- 预览网格只用于流程和趋势检查。
- 未收敛、网格无效或近壁层未验证时，不输出工程通过结论。
- 缺少真实求解字段时会明确阻止云图，不生成假数据。
- 未提供可比的实验或 Fluent 数据时，不宣称满足固定误差。

任务和产物保存在 `web-data/jobs/`，原始 STEP 不会被覆盖。

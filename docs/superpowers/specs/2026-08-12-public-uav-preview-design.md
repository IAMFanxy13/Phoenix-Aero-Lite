# 公开无人机预览模型设计

## 目标

用同一架外形清晰的小型固定翼无人机替换 README 两张界面预览中现有的积木飞机和方块，同时保持截图来自真实 Phoenix Aero Lite 网页流程。

## 范围

- 修改公开端到端测试使用的合成 STEP 模型。
- 重新生成“主翼表面真实点选”和“求解后壁面 Y+”两张截图。
- 不修改用户的 `Air.STEP`、业务求解逻辑或科学权限门槛。
- 不把渲染图或测试数组表述为风洞、飞行试验或真实飞机的工程结论。

## 几何设计

模型使用现有 Gmsh/OpenCASCADE API 参数化生成，不新增建模引擎：

- 流线型机身和圆滑机鼻；
- 左右对称的后掠主翼；
- 左右平尾；
- 单垂尾；
- 各部件形成可导入、可三角化、可点选的 STEP 几何。

模型比例面向小型固定翼无人机，保持明显的飞机轮廓和足够大的主翼拾取区域。几何生成固定参数，保证 CI 和本地截图可复现。

## 截图与数据真实性

- 两张截图必须来自真实浏览器端到端测试。
- 主翼截图必须完成真实表面点击、高亮和参考量更新。
- Y+ 截图使用同一无人机表面网格，并使用明确标注的确定性测试标量场验证可视化链路。
- README 继续保留“截图不是气动正确性证明”的说明。

## 测试

- 验证 STEP 能由 Gmsh/OpenCASCADE 重新导入并包含有效体和曲面。
- 验证模型包围盒和部件特征符合固定翼无人机形态。
- 验证真实表面点选后选择数量与参考量发生变化。
- 验证 Y+ 场景显示的是无人机表面而非方块。
- 运行端到端测试与完整回归测试，并人工检查两张生成截图。

## 验收标准

- 两张 README 图片中均能一眼看出小型固定翼无人机轮廓。
- 两张图片使用同一架模型。
- 主翼点选高亮清楚可见。
- Y+ 色标覆盖无人机表面，且界面保留单位/无量纲和可信度提示。
- 不修改或伪造用户模型、真实求解结果和科学结论。
